# Pencatatan eksperimen TP2

Belum ada eksperimen model pada tahap repository/audit. Jangan mengisi skor yang belum diukur.

Satu run berikutnya memiliki ID unik `YYYYMMDD-owner-task-description`, commit kode, hash input, target terverifikasi, metric sesuai rubric, batas cycle train/validation, seed, preprocessing yang dipelajari hanya pada fold train, parameter, hasil per fold dan status runtime. Gunakan split yang sama untuk perbandingan yang diklaim sebanding. Test hanya untuk prediksi final setelah keputusan dikunci.

Salin `run_template.json` untuk metadata kecil yang layak direview; simpan model, prediksi per record dan artifact besar di `experiments/runs/` yang ignored. Jangan menyimpan ID/data/text mentah dalam laporan Git. Setiap anggota memiliki namespace sendiri dan bertanggung jawab menjelaskan eksperimennya.
